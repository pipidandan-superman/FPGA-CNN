# 第一章 人工智能基础：网络就是函数

### 3. 先看一个最小问题：用函数拟合数据
- 示例：给定若干 `(x, y)` 点，寻找 `y = ax + b`。
- `a、b` 是参数；输入 `x` 经过函数得到预测值 `ŷ`；真实值为 `y`。
- 重点：AI 的“学习”首先是找一组参数，而不是凭空产生知识。
- 图示：散点、直线、残差。

### 4. 一次函数不够时：二次函数增加表达能力
- `ŷ = ax² + bx + c` 可以表达弯曲关系。
- 三个参数带来更大的函数集合；参数越多，能拟合的关系越复杂。
- 引出本工程：像素不是直接对应数字，识别需要组合很多局部关系。
- 图示：同一数据分别用直线和抛物线拟合。

### 5. 把“好不好”写成损失函数
- 以均方误差说明：`L = 1/N Σ(ŷ-y)²`；分类时用交叉熵描述正确类别分数是否足够高。
- 损失是一个关于参数的函数：`L(θ)`；训练目标是让它变小。
- 注意：损失小不等于现实世界一定可靠，数据分布和测试集仍然重要。
- 图示：预测点到真实点的误差，旁边标出损失曲面。

### 6. 为什么叫“网络”：函数的组合
- 一个神经元可写成 `z = w·x+b`，再经过激活函数 `a=f(z)`。
- 多个神经元组成层，多层函数复合：`f3(f2(f1(x)))`。
- 线性函数层层叠加仍是线性函数；ReLU 等非线性让网络表达弯折、门控和分段关系。
- 图示：输入、线性变换、ReLU、输出的函数链。

### 7. 前向传播：把输入送过函数
- 以一个二维输入和两层小网络演示：逐层计算 `z`、激活值和最终输出。
- 对分类任务，最后得到 10 个分数，最大分数对应预测数字。
- 对应本工程的 `forward()`：卷积 -> ReLU -> 池化 -> 全连接 -> ReLU -> 全连接。
- 图示：数据从左向右流动，标出每个张量形状。

### 8. 反向传播：误差如何告诉每个参数
- 先计算输出误差，再利用链式法则把影响逐层传回。
- 梯度 `∂L/∂w` 表示参数增加一点时损失如何变化。
- 直觉：离输出越远的参数也能收到“应该往哪边改”的信号。
- 可用一条三节点计算图演示乘法和加法的梯度传递。

### 9. 梯度下降：在雾中的山上找下坡方向
- 更新式：`w ← w - η ∂L/∂w`；`η` 是学习率。
- 小批量梯度下降用一部分样本估计方向，速度和噪声之间折中；D 盘脚本使用 batch=100。
- Adam 是对梯度做自适应缩放的优化器；补充资料中的训练配置为 `lr=0.001`。
- 图示：二维损失曲面、几条更新轨迹。

### 10. 为什么可能停在局部最优
- 非凸损失面可能有局部低谷、鞍点、平坦区域；初始参数、学习率和数据顺序会影响路径。
- “下山”目标是找到足够好的解，不保证找到全局最低点。
- 工程判断标准应放在验证集表现、稳定性和部署约束，而不是只看训练损失最低。
- 图示：多个谷底，标出局部低谷与较低的另一处谷底。

### 11. 泛化：记住训练样本不等于学会规律
- 训练集用于调参数，验证集用于选配置，测试集用于最后一次客观检查。
- 训练准确率高、测试准确率低是过拟合；两者都低可能是欠拟合、数据或实现问题。
- 本工程要同时关注 MNIST 测试图像与真实摄像头经过阈值、ROI、下采样后的分布差异。
- 图示：训练/测试曲线及“真实摄像头域差异”提示。

### 12. 从全连接到卷积：利用图像结构
- 全连接把 784 个像素全部混在一起，参数多且忽略邻域。
- 卷积核只看局部窗口，同一个核在不同位置复用；早期可学边缘、方向和局部笔画。
- 池化压缩空间尺寸，保留局部强响应，降低后续计算量。
- 图示：5x5 窗口在 28x28 图像上滑动，突出权重复用。

### 13. 第一章小结：从函数到可部署模型
- 一句话：模型是一组参数化函数；训练通过损失和梯度调整参数；泛化决定它是否能处理新输入。
- 接下来把这条抽象链映射到本工程每一层、每一个存储和接口。
- 过渡问题：一张 28x28 图像如何变成 10 个数字分数？

# 第二章 本工程的网络结构与数据通路

### 14. 工程全景：摄像头、预处理、CNN、显示
- OV5640 摄像头输入，中央 ROI 提取，HDMI 显示；Zynq PS 与 PL 协同。
- 数据流：视频像素 -> 灰度 -> 二值 -> 28x28 -> CNN -> 0~9 -> 显示。
- 图示：一张主数据流图，标出每段由 PL、PS 或外设完成。

### 15. 输入预处理：640x480 到 28x28
- `vio_to_gray.v`：中心 `112x112` ROI，灰度公式 `Y=(77R+150G+29B)>>8`。
- `gray_yo_bin.v`：阈值 128，输出二值笔画。
- `image_downsample.v`：每个 4x4 区域统计 16 个点，达到 `POOL_TH=4` 输出 1，得到 28x28。
- 强调：这一步决定摄像头输入是否接近训练数据，属于模型输入的一部分。

### 16. 卷积层：28x28 -> 24x24x30
- 30 个 `5x5` 卷积核，valid 卷积，步长 1，不补零。
- 输出尺寸：`28-5+1=24`，每个位置得到 30 个通道值。
- RTL `cnn_conv_5x5.v` 使用行缓存、25 个乘法/选择和累加；二值输入使乘法退化为“像素为 1 才加权重”。
- 图示：一个 5x5 窗口、30 个通道和时序流水。

### 17. ReLU 与最大池化：24x24x30 -> 12x12x30
- ReLU：负值置零，保留正响应；卷积 RTL 中已把 Bias 和 ReLU 纳入输出路径。
- `cnn_maxpool_2x2.v`：2x2、stride 2，空间尺寸减半。
- 池化后每帧有 `12*12*30=4320` 个特征。
- 图示：一个通道上的 2x2 最大值和 30 通道并行概念。

### 18. 全连接分类头：4320 -> 100 -> 10
- FC1 权重形状为 `100x4320`，Bias 100；ReLU 后进入 FC2。
- FC2 权重形状为 `10x100`，输出 10 个类别分数；argmax 得到 0–9。
- `test_cnn_inference.py` 给出纯 Python 参考前向；Vitis `cnn_inference.c` 在 PS 上执行这两层。
- 图示：扁平化后矩阵乘法，旁边放尺寸表。

### 19. PS/PL 划分：同一个网络的两种执行位置
- PL：输入二值图、5x5 卷积、ReLU、2x2 池化，强调流式、并行、固定尺寸。
- PS：BRAM 读取、定点反量化、HWC->CHW、FC1、ReLU、FC2、argmax，强调软件灵活性。
- 纯软件路径保留为基线，用于先验证网络和参数；加速路径把前半段下沉到 PL。
- 图示：软件基线与硬件加速版上下对照。

### 20. 数据布局与帧间协同
- PL 写 BRAM 为 HWC：`[y][x][c]`；FC 权重按 CHW 排列，PS 需重排。
- `pool_to_ps_ram_ctrl.v` 按像素和通道写入 4320 个特征，完成后产生 PS 中断。
- `pp_ram_ctrl.v` 使用 Ping-Pong RAM，让摄像头写一块 RAM 时 CNN 读取另一块，形成帧级流水。
- 图示：两个 RAM 的交替时序和中断点。

### 21. 量化：让浮点模型适应 FPGA 数据通路
- `conv_weight_gen.py`：按最大绝对值计算 `W_SCALE`，权重量化到有符号 8 位并生成 COE。
- Bias 和特征路径使用 16 位；PS 以 `W_SCALE=97.625622` 反量化池化特征。
- 量化会引入误差，验证要比较浮点输出、量化软件输出、RTL 输出和上板输出。
- 图示：浮点数 -> INT8/INT16 -> COE/BRAM -> 反量化。

### 22. 第二章小结：模型图就是硬件数据流图
- 每一层都回答三个问题：输入形状是什么、参数在哪里、输出交给谁。
- 本工程网络的核心尺寸链：`1x28x28 -> 30x24x24 -> 30x12x12 -> 4320 -> 100 -> 10`。
- 过渡到第三章：结构确定后，如何从数据和训练开始，把它可靠地做出来？

# 第三章 完整开发流程：从模型选择到 FPGA 上板

### 23. 任务定义与验收指标
- 先定义任务：识别 0–9，输入是 MNIST 风格二值图还是摄像头 ROI，输出是类别和显示结果。
- 同时定义指标：分类准确率、端到端延迟、吞吐、资源、功耗和输入鲁棒性；本项目当前未把这些实测数值写入大纲。
- 先固定数据格式、坐标方向、阈值和结果显示规则。

### 24. 数据准备与输入对齐
- MNIST 图像 28x28、标签 0–9；D 盘提供压缩文件、解压文件和读取代码。
- 训练前统一形状、数值范围和前景颜色；摄像头路径需要复制 ROI、灰度、二值、4x4 投票规则。补充资料的通用训练脚本默认使用归一化灰度图，而 FPGA 推理脚本会把输入二值化，因此正式复现时必须明确采用二值训练、灰度训练，或增加一致的预处理实验。
- 划分训练/验证/测试集，额外保留真实摄像头样本做域差异检查。
- 图示：数据集、预处理脚本、摄像头样本的对齐关系。

### 25. 模型选择与尺寸推导
- 先选能解释、能部署的小模型：单通道、5x5 卷积 30 通道、2x2 池化、100 隐藏单元、10 类输出。
- 用尺寸公式提前检查：卷积输出 24x24，池化输出 12x12，FC 输入 4320。
- 模型选择同时考虑准确率、乘加次数、BRAM/逻辑资源和接口复杂度。

### 26. Python 训练：从初始化到参数更新
- D 盘 `train_convnet.py` 的可复现配置：MNIST；`max_epochs=20`；mini-batch=100；Adam；学习率 0.001；每轮记录 train/test accuracy。
- `simple_convnet.py` 明确层序列和参数形状；`Trainer` 完成抽样、反向传播、优化器更新和评估。
- 讲解训练循环：取 batch -> forward -> loss -> backward -> Adam update -> 记录曲线。
- 课堂演示建议：展示一次 loss 下降和一次参数变化，而不是只展示最终数字。

### 27. 训练结果与泛化检查
- 看训练/测试曲线是否同步；检查误分类样本，分析笔画粗细、平移和断裂。
- 在真实摄像头预处理后的 28x28 图像上做独立测试；不要用训练集结果替代板级验证。
- 结果页保留“待实测”字段：准确率、混淆矩阵、摄像头域准确率。

### 28. 参数导出与软件基线
- `params.pkl` 保存 W1/b1、W2/b2、W3/b3；推理脚本将参数导出为 Conv/FC 的 TXT。
- 先用 `test_cnn_inference.py` 或 D 盘 `fpga_cnn_predit.py` 验证浮点前向，保存中间结果：conv、ReLU、pool、FC1、FC2。
- 软件基线的意义：RTL 出错时，可以定位到输入、层计算、布局或量化，而不是盲目看最终分类。

### 29. 量化与 COE 生成
- 选择量化格式并记录 scale、截断和符号规则；卷积权重 INT8，Bias/中间结果按工程 16 位路径处理。
- 生成 `param_conv_h*.coe`、`param_conv_b.coe` 等初始化文件，检查权重顺序与 RTL 位切片方向。
- 量化后运行同一批样本，比较浮点和定点 logits/argmax，统计量化误差。

### 30. RTL/Block Design 实现
- 按数据流实现预处理、Ping-Pong RAM、卷积、池化、BRAM 回传、AXI/中断和 HDMI 显示。
- Block Design 连接 PS、AXI BRAM、AXI Lite、VDMA/HDMI；确认时钟、复位、地址范围和中断连接。
- 工程器件为 Zynq-7000 `xc7z010clg400-1`，以工程约束和 IP 配置为准。

### 31. 分层验证：从数值到时序
- Python 数值验证：固定输入，保存每层参考结果。
- RTL 仿真：用 `3_sim/tb_cnn_conv.v` 等 testbench 检查卷积窗口、通道、Bias、ReLU、池化和帧完成信号。
- 集成验证：检查 BRAM 地址、HWC/CHW 转换、中断、Ping-Pong 交替和视频时序。
- 每次验证保存完整 transcript/日志，不只保存最后一句 PASS。

### 32. Vitis 软件与硬件协同
- PS 程序初始化 VDMA、摄像头/显示控制和中断；收到池化完成中断后读取 BRAM。
- `Read_BRAM_Pool_Output()` 完成定点反量化和 HWC->CHW；`cnn_forward_accelerated()` 完成 FC1、ReLU、FC2 和 argmax。
- 调试时打印 10 个分数和最终类别，并与 Python 参考逐层比对。

### 33. 上板闭环与问题定位
- 闭环：摄像头 -> ROI/二值/下采样 -> PL CNN -> BRAM -> PS 分类 -> HDMI 叠加显示。
- 若结果错误，按顺序定位：输入图像、28x28 数据、卷积输出、池化 BRAM、量化/布局、FC 分数、显示控制。
- 演示建议准备一张“正常样本”和一张“边界样本”，展示错误定位方法。

### 34. 完整开发流程回顾
- 任务定义决定输入和指标；数据预处理决定模型看到的世界；训练得到参数；导出和量化把参数变成硬件格式；RTL/PS 把函数变成可执行数据通路；分层验证保证结果可信。
- 结尾回到第一章：部署后的 FPGA 电路仍然是在计算一个函数，只是函数的每一段被放到了最合适的执行位置。
