1. 以三章结构组织大纲：AI 基础、工程网络结构、系统开发流程。
2. 第一章从 y=ax+b 与 y=ax²+bx+c 开始，解释参数、损失函数、梯度、链式法则、前向传播、反向传播、梯度下降、局部最优与泛化。

4. 第三章沿“任务定义 -> 数据 -> 模型 -> 训练 -> 验证 -> 导出 -> 量化 -> RTL -> 仿真 -> 上板 -> 闭环验证”展开。

6. 先由用户审核页数、教学深度和重点，再制作正式 PPTX。
