# 已核对内容
- 工程顶层包含 `0_doc`、`1_log`、`2_rtl`、`3_sim`、`4_constrain`、`6_visio`、`7_proj`、`8_num_coe`、`9_ip`、`10_cnn`、`11_python`。
- CNN 参数形状：卷积权重 30x5x5，卷积偏置 30，FC1 100x4320，FC1 偏置 100，FC2 10x100，FC2 偏置 10。
- 输入链路：OV5640 -> RGB565/RGB888 -> 中央 112x112 ROI -> 灰度 -> 二值化 -> 4x4 投票下采样为 28x28。
- PL 链路：5x5 valid 卷积 30 通道得到 24x24x30，ReLU，2x2/stride2 最大池化得到 12x12x30，写入 AXI BRAM。
- PS 链路：BRAM 读取、16 位定点按 `W_SCALE=97.625622` 反量化、HWC 转 CHW、FC1 4320->100、ReLU、FC2 100->10、argmax；中断由 `pool_to_ps_ram_ctrl` 产生。
- 显示链路：PS 通过 AXI Lite 写入识别数字，VDMA/HDMI 输出视频。
- 仓库内未发现训练脚本、数据集或明确的训练日志；发现的是已导出的浮点参数、推理脚本、量化脚本和部署代码。
