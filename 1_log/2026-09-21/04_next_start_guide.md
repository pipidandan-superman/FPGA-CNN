# 下次开始阅读
1. 先阅读本目录的 `03_validation_summary.md` 和 PPT 大纲审核意见。
2. 若用户通过大纲，读取 presentations 的实现与视觉规范，选择是否制作正式 PPTX。
3. 正式制作前确认目标听众、时长、是否需要演示截图，以及是否需要把训练流程补成可运行 notebook。
4. 制作后渲染每页检查文字溢出、网络尺寸图和 PS/PL 数据流图。

# 不要立即做的事
- 不要直接把仓库参数文件当作训练代码。
- 不要在没有测量证据时写准确率、FPS、延迟或资源占用。
- 不要把纯软件推理路径和硬件加速路径混成一条实现。

# 下一次成功标准
用户认可三章结构、页数和教学深度后，再进入 PPTX 设计与生成。
